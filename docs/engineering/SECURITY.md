# 安全与信任边界

M0-A v1.0 · 本文不是审计报告或法律意见。

## 1. 信任模型

用户钱包授权资金动作；合约执行已经固定的规则；Cloudflare 托管元数据与事件投影。平台没有用户私钥，并不意味着合约不存在托管、漏洞或代币冻结风险。现实交付依赖双方行为，签到依赖披露的认证方，稳定币还受发行方权限影响。

| 威胁 | 必须采取的措施 | 残余限制 |
| --- | --- | --- |
| 收款地址或比例被替换 | 发布时冻结并哈希；钱包前确认实际链上参数 | 被盗钱包仍可能主动签署恶意交易 |
| 同一本金多次退款/分账 | 单向状态、不变量、nonce、先记账后交互 | 需合约测试与独立审阅 |
| 队列重复、并发、事件重放 | 唯一键、数据库事务、链上幂等 | 不可宣称端到端 exactly-once |
| 假付款回执 | 核对链/合约/日志/金额/收款人/确认状态 | RPC故障会延迟展示 |
| 恶意网页诱签 | SIWE域隔离、CSP、固定部署清单、签名前摘要 | 浏览器/扩展被攻陷仍有风险 |
| 管理员滥权 | 不可升级资金合约、无任意提款、只暂停入金 | 外部代币发行方权限不受控制 |
| 交付争议永久锁款 | 双签协议+明确超时退出 | 付款人偏向的退出机制可能被滥用 |
| dev 接到真实资产 | 环境/资源/密钥/chainId隔离，默认测试网 | 必须实际验证绑定 |
| 文件泄露/脚本注入 | 私有R2、对象级授权、不可执行下载、输入净化 | 链上地址/金额公开且无法抹除 |
| 服务停机 | 保留ABI/原规则快照/合约退出方法 | 用户仍需钱包和网络Gas |

## 2. 认证与授权

SIWE 验证签名、domain、URI、chainId、nonce、issuedAt、expirationTime；nonce 10分钟单次有效，原子消费。会话 HttpOnly/Secure、host-only cookie、适当 SameSite、24小时有效，登出撤销；写请求校验 Origin 和 CSRF 防护。跨环境不共用 cookie 或 nonce。[S09](../planning/SOURCES_AND_PROVENANCE.md)

API 的 actor 从会话解析，不能信任请求中的 ownerAddress。创建、读私密文件、编辑草稿、获取通知均做对象级权限检查。链上操作再次由 msg.sender/签名角色判断。邮箱不是链上提款认证；本版不能通过重置邮箱迁移旧钱包权益。

SIWE 只是登录，不是转账或 token 授权。付款前分别说明 token approve 与业务入金，默认精确额度，不要求助记词。未验证智能合约钱包的 EIP-1271 路径不得默认为支持。

## 3. 内容与附件

公开规则文件保存原始字节与哈希，已发布不能替换同一版本内容。用户可编辑的资料需净化；不渲染任意HTML/脚本/SVG事件，不把用户输入拼进SQL或命令。

R2 桶私有，访问凭证短时且只允许指定对象/操作；对象前缀不能由客户端越权指定。上传限制建议每文件10MB、每交付5件（M0-B实测后固定），验证扩展名、MIME和内容；返回 `Content-Disposition: attachment`、`nosniff`。未具备安全检查能力时禁用高风险格式，不宣称已经扫描安全。

公开链接只提供公开内容，私密文件按双方角色授权。隐藏页面不等于链上隐私；Rewards 名单公开披露。默认不收证件或敏感身份数据。

## 4. 供应链与凭据

依赖锁版本和 lockfile；PR审查新包、生命周期脚本、许可和已知漏洞；CI只给予必要权限，不在不可信PR中运行带秘密的命令。禁止 `curl | sh` 或复制赛事/邮件中的不明脚本执行。

私钥/助记词不放到Cloudflare、不放仓库、不放聊天、不进入日志；用户钱包签署资金交易。构建账户没有链上部署权限。Cloudflare的运行密钥与构建密钥分开、开发与生产分开。日志不记录原始签名、cookie、token、预签名URL或附件内容。

## 5. 审计与运营

每次主网放行需要权限审阅、关键合约独立安全复核、资金不变量测试、资金上限、风险披露和用户授权。未经审计时不可展示“已审计”标记。真实资金上限和管理员地址在放行前确定；未确定则生产界面保持主网写操作禁用。

发生异常：停止新入金入口→保留合法退出→核对部署/代码/事件→通知受影响用户并给出可验证状态→修复新版本并保留旧版权益访问。不得为简化统计而重置数据库掩盖损失，不得通过后台把争议款付给自己。

上线前检查适用的隐私、服务条款及稳定币业务要求；未进行法律审查不宣称全球无限制使用。这里不做任何合规结论。

## 6. 必须执行的滥用测试

未登录、错地址、错chainId、过期nonce、重用nonce、重放双签、私密文件ID枚举、修改已发布金额、伪造webhook、重放日志、数据库回滚、重复队列消息、跨环境cookie、恶意上传、超大请求、任意URL抓取、代币冻结、领取失败后重试、暂停后退款可用。

这些测试属于后续阶段，不在M0-A声称通过。具体编号和验收归属见开发计划。
