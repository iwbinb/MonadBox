## 1. 执行规则与用户最新决定

读取远端 → 长期dev开发 → 当前批次测试 → dev→main PR → 报告并停止。Bill决定合并及下一批；不强推、不删dev、不自动连续展开所有工具。

用户已明确“这些后面再试，继续开发功能”。因此**真实钱包测试不再作为继续编码/本地验证的前置条件**；C-T03和各工具真实资金验收保持待完成。测试后置不等于测试通过，也不授权自动签名、主网或公开业务入金。此决定记为ADR-19，替代旧文档中“C-T03未通过不能开始M1编码”的限制。

六工具终态不变。M1按可审阅的小批次交付，先草稿/合约，再发布/分享，再资金交互，最后补齐真实网络验收。每批仍单独PR、由用户合并。主网始终单独通过G-07。

## 5. M1-A：草稿与合约基础（本批）

A-01 四步创建向导，金额最小单位、人数/容量、时间顺序、非零地址校验，中文/英文规则摘要。

A-02 本地保存/编辑/删除/刷新，最多40份；16KB版本化JSON导入导出；损坏数据保留、Web Locks/revision冲突保护、保存失败可导出。明示不是云端账户或付款链接。

A-03 GroupEscrowV1：create/contribute/leave/finalize/cancel/creditRefund/settle/withdrawFor、固定暂停管理员、不可变条款、资金守恒及版本化编码；仅在本地部署测试。

A-04 生成ABI/bytecode，TypeScript与Solidity规则哈希一致；成功/失败/退出取消三种本地Anvil情形。

A-05 文档、检查记录、截图与PR。业务publish/payment开关不变，远端资源不增加。

验收证据：169项Vitest（其中57项Group单元测试）；55项Foundry（37项Group＋18项探针）；44项Playwright（20项Group桌面/手机尺寸）；Group本地Anvil三场景25个操作。准确提交与运行编号见[M1-A验收](M1-A_ACCEPTANCE.md)，新提交结果以对应CI为准。

## 6. M1-B：成团发布与分享（下一批）

B-01 在现有钱包薄适配上实现SIWE登录、单次nonce、会话/Origin/对象级授权，不将登录签名视为付款授权。

B-02 D1保存草稿/公开规则元数据与发布记录。保留原始UTF-8字节、metadataHash、schema与revision；发布后关键规则不可改。生产/Preview独立绑定和environment_guard实测，资源未就绪可先本地验证。

B-03 合约版本/资产登记、发布摘要与钱包调用接口；发送前按当前链时间重验旧草稿，拒绝过期/错链/错hash，不从localhost测试地址生成公开登记。实际部署/发布由用户显式授权签名，CI不代做。

B-04 实现 `/b/:publicId`：无需登录可读公开条款与链状态，未发布/未知/取消/过期/加载失败分别提示；本地草稿URL永不冒充公开付款页。

B-05 校验重复发布意图、过期nonce、越权、元数据篡改、交易unknown/replaced和刷新恢复；在Mock/本地链测试完整发布→另一浏览器读取，分别标记未完成的远端部分。

停止点：独立PR；不顺带实现Split或其他工具。不需要用户现在提供私钥，也不提前绑定R2/Queues。

## 7. M1-C / M1-D：资金交互和真实验收

M1-C实现：精确授权与固定价参与；截止前退出；未达标/取消退款先归属credit再提款；成功组结算时间锁与固定受益人；记录/工作台、原hash恢复、索引迟到提示。金额/角色/状态最终以链上为准，D1仅为可重建投影。未就绪时资金按钮保持禁用。

| ID | 必须覆盖的Group规则 |
| --- | --- |
| GR-01 | 未达最低人数截止后全退，组织者不能提 |
| GR-02 | 达标但未截止仍可退出，人数与locked同步减少 |
| GR-03 | deadline前1秒/等于/后1秒合法动作唯一，不依赖抢先finalize |
| GR-04 | 满额/重复加入/退出后重进/重复退款拒绝 |
| GR-05 | READY但未到settleNotBefore禁止结算，到时可被任何人触发 |
| GR-06 | 取消与结算仅一条成功；已退出不重复分配，已结算不再退款 |
| GR-07 | 暂停新入金不阻退出、退款归属或领取 |
| GR-08 | 手机、刷新、拒签、RPC故障、索引延迟与恢复 |

M1-A已测试部分合约规则，但不代表以上全部UI/公网路径完成。M1-D在用户安排时完成真实AUSD/EOA钱包、部署清单/源码验证、成功和退款场景、重复拒绝、资金守恒、真实浏览器/远端资源隔离，并补齐M0-C未完成项。未经独立复核不能宣称审计完成。
