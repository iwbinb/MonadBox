# 决策记录与放行条件

M0-A v1.0 · 2026-09-27

## 1. 用户已明确的约束

U-01 仓库为 `iwbinb/MonadBox`；U-02 六工具集合站，先Group再Split组合；U-03 在长期dev开发，PR合并main后Cloudflare自动发布；U-04 用户决定合并；U-05 本次只完成M0-A规格阶段。

下面的技术与业务默认值是本次设计基线，不冒充用户逐项批准。对不可逆资金规则作修改时，应修订规格并经阶段PR审阅，再写业务代码。

## 4. 待审阅的产品取舍

### Group不等于服务托管

成功成团在约定时间即可结算；若用户需要验收后付款，应使用Deliver/Milestones。为了贴合演示而临时增加“后台确认服务完成”会改变权力模型，不能无规格加入。

### 争议必须有退出

Deliver/Milestones与Attend都采用明确期限和默认退款路线，而非永久冻结或平台管理员主观裁决。这个选择有偏向和可被滥用的可能，在市场验证中必须问双方是否接受；不包装成完全公平或无风险。

### 收款与退款兼容

只有已解除规则约定退款义务的本金能分账。尚在验收/申诉/未成团风险中的钱继续留在原合约；不能因“已达到人数”就展示无条件全额退款同时又把钱打给受益人。

## 5. 变更模板

变更ID/日期；原规则；新规则；受影响的角色、状态、旧订单和测试；是否增加权限或资金风险；用户批准位置；迁移/旧版退出办法；代码与部署版本。未合并决定不得静默覆盖已发布Box的条款。
